Детекция трещин на асфальте 
-
Программа с двухэтапным пайплайном детекции и сегментации трещин в асфальте. 


Модели, которые были обучены:
-
  -`yolov8n-cls.pt`
  
  -`yolo26n-sem.pt`


Архитектура проекта:
-
`imagesForTest/`  - папка для изображений  

  -`images` - папка для ваших изображений, на которых вы хотите найти трещины  

  -`resultImages` - папка для сохранения результатов  


`models/` - папка с обученными моделями

  -`classificationModel.pt` - модель для классификации
  
  -`segmentationModel.pt` - модель для сегментации 


`src/` - папка со скриптами 

  -`cls.py` - обучение модели для классификации
  
  -`cls_test.py` - проверка обученной модели классификации
  
  -`seg.py` - обучение для сегментации
  
  -`seg_test.py` - проверка обученной модели сегментации
  
  -`main.py` - сама программа. Точка входа
  
  -`separation.py` - служебный файл, не выполняет функций в текущем проекте
  

Запуск проекта: 
-
Потребуются зависимости:

`pip install ultralytics opencv-python numpy`

Поместите фотографии, на которых вы хотите найти трещины в папку imagesForTest/images

Укажите в переменной image в main.py название вашего изображения

  -`python src/main.py`

main.py на вход получает изображение, классифицирует его - Cracked/Uncracked, при Cracked запускает сегментацию и после визуализирует маску трещины.

получите результат в imagesForTest/resultImages


Воспроизведение результатов
-
  Для воспроизведения работы готовых моделей необходимо:

  -`Скачать репозиторий.`

  -`Установить зависимости.`

  -`Поместить тестовое изображение в imagesForTest/images/.`

  -`Указать его путь в src/main.py.`

  -`Запустить:`

  -`python src/main.py`


Примечание
-
Модели classificationModel.pt и segmentationModel.pt являются уже обученными моделями, поэтому для запуска main.py повторное обучение не требуется.
